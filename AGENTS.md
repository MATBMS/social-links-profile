# Project guidance

## Collaboration

The user is an aspiring AI-driven developer learning to build software through prompts and collaboration with an AI coding agent. The user describes desired outcomes and provides feedback while the agent takes ownership of implementation from start to finish. Give clear, beginner-friendly explanations of completed work so the user can learn from the process.

## Implementation

This repository is a Frontend Mentor newbie project. Keep solutions simple, readable, responsive, accessible, and appropriate for a beginner.

- Use only HTML, CSS, and vanilla JavaScript. Do not install or introduce libraries, frameworks, packages, build tools, or dependencies.
- Use JavaScript only when genuine interactivity requires it.
- Inspect existing files and the README before editing, and preserve unrelated work.
- Use semantic HTML and modern CSS. Avoid overengineering.
- Verify layout across screen sizes and check accessibility, including keyboard focus, image descriptions, and color contrast.

## Public repository and private material

This is a public repository. Never publish secrets, credentials, tokens, private URLs, personal data, sensitive configuration, private notes, or user-specific comments unsuitable for a random visitor.

- Code comments must explain the public project rather than communicate privately with the user.
- Keep sensitive values in ignored local files or environment variables, with safe placeholders in tracked example files.
- `docs/` is private local workflow material and is excluded from version control. Keep design references and private notes there.
